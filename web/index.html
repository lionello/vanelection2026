Unsupervised maps of sourced candidate evidence: mayor, council, Park Board and school trustees. Not an endorsement tool. Nothing here scores candidate quality.

Methods report Exports

Topic weights

Each covered topic contributes equally by default (1.0). Set 0 to drop a topic. Missing topics are excluded, never zero-filled.

Combined-map block weights

Blocks are L2-normalised, then scaled by √weight, so dimensionality never decides influence. Candidates missing a weighted block are excluded.
